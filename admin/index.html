Shows

Agregá, editá, ocultá, destacá y ordená los eventos. Los cambios se guardan en este navegador y se pueden exportar a shows.json para publicar en GitHub Pages.

Cómo funciona esta versión: GitHub Pages es un sitio estático, por lo que una página publicada no puede modificar por sí sola el archivo data/shows.json del repositorio. Este panel permite administrar todo visualmente, importar/exportar el JSON y dejarlo listo para reemplazar en GitHub. Más adelante podemos conectar una base/CMS o automatizar el guardado con GitHub Actions.
